照片分類上傳到 Google 雲端

選擇照片 → 輸入文字（會變成檔名）→ 選擇資料夾與子資料夾 → 一鍵上傳到 Google 雲端硬碟。

第一次使用：設定教學（約 5 分鐘）
  1. 到 Google Cloud Console 建立專案，並在「API 和服務」啟用 Google Drive API。
  2. 「OAuth 同意畫面」選「外部」，把你自己的 Gmail 加入「測試使用者」。
  3. 「憑證」→「建立憑證」→「OAuth 用戶端 ID」→ 類型選「網頁應用程式」。在「已授權的 JavaScript 來源」加入你開啟本頁的網址（只填網域，例如 http://localhost:8000 或 https://帳號.github.io）。
  4. 複製產生的「用戶端 ID」，貼到下方欄位。
  5. 本頁不能直接雙擊開啟（file://），請用本機伺服器或放到有 https 的網站。

2. 設定分類資料夾

「資料夾連結或 ID」可貼上雲端資料夾網址；留空則在「上層資料夾」底下依名稱尋找，找不到就自動建立。

  • 照片沒有選資料夾：自動存入以今天日期命名的資料夾（例如 20261023）。
  • 照片沒有輸入文字：檔名自動命名為「資料夾名稱_日期_流水號」（例如 風景_20261023_01.jpg），流水號會接續雲端裡已有的號碼。
  • 填了「子資料夾」：會在所選資料夾裡再建立（或沿用）該名稱的子資料夾。
